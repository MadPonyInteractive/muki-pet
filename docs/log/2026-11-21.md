## Built eyebot v0.1.0

- Read the mods docs. The first idea was a `Client` module with a frame clock and pointer events, then dropped: `Client` can't draw `Svg`.
- Chose one self-animating SVG (CSS keyframes from a pre-run simulation, plus `:hover` strips). See `architecture/how-it-works.md`.
- **Browser preview, worked:** rolling, wheel spin, head lag (about 14° tilt at full speed leftwards), eyes leading the motion, stop-and-watch on hover, eyes following the mouse strip, happy eyes on hover, blinking while paused.
  - A first test page with `<iframe sandbox src=robot.svg>` showed nothing; opening `robot.svg` directly worked. Not chased further.
  - Calling `.play()` / `.pause()` from JS in devtools takes animations away from CSS `animation-play-state`, which spoils hover-pause tests. Reload the page before testing hover.
- `claude plugin validate`: passed. `claude plugin test`: 3/3 passed.
- No TypeScript compiler installed, so no type-check. Didn't download one without asking.
