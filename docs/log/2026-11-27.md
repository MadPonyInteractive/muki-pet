# 2026-11-27

## MPI-24: celebrate (fireworks) never fired

Fabio: typed "perfect", "1" and "Okay, looks great" in Desktop, no fireworks.

- **Checked: the phrase list.** `isConfirmation` accepts all three. Not the cause.
- **Checked: the types** (regenerated for Claude Code 2.1.332 with `claude --plugin-dir ./muki-pet` in a real terminal; a run with no TTY exits at once and writes nothing). `turn.start`'s `text` is the typed prompt as a plain string.
- **Checked: real samples** from a temporary debug write to `$.store` (`debug.turnStart`, `debug.promptSubmit`; since removed). `claude -p "perfect"` and Desktop both sent the plain text (`"perfect"`, `"Perfect."`), no prefix, no wrapper, main loop (no `agentId`), and the brain went to `celebrate` with nothing holding the redraw. Fabio saw the fireworks for "Perfect." sent while Claude was idle.
- **Found: the cause.** A message typed while Claude is still working goes into the running turn. `prompt.submit` sees it (with `turnId` set to the running turn), but **no `turn.start` fires for it**. Seen live: "Seedance 2.0 is still there.", "I'm going to test if it still works in the app." and "Yeah, it triggered." all have a `prompt.submit` and no `turn.start`. The check sat on `turn.start`, so a "perfect" sent while Claude was still wrapping up (the usual moment) was never read.
- **Side find:** Desktop's transcript can store a message as blocks, with pending `<system-reminder>`s (side-session notes) before the typed text. That is not in `e.text`: the samples were clean.
- **Fix:** the check moved to `prompt.submit` (`register.tsx`), only for your own words (`saidByYou` in `character/confirm.ts`: origin `composer`, `bridge`, `sdk`, or a plugin's `asUser`; no slash command, no `isMeta`). The `prompt` event carries `confirmed` now; `turnStart` carries nothing. In the idle case `prompt` comes first, then `turnStart`'s alert (priority 20) stays under celebrate (25).
- **Tests:** `celebrate.test.ts` (mid-turn "it worked" with no turn of its own), and `register.test.tsx` "Perfect." through the real hooks with Desktop's shape (origin `composer`, `turnId` of the running turn, no `turn.start`); a `task-notification` with the same text does not celebrate.
- **Checks** (HEAD plus MPI-24's files only, in a scratch copy, since MPI-23's probe was uncommitted in the shared tree): tsc clean, golden identical (3,648), `claude plugin test` 59/59, `claude plugin validate` passed (with its usual warnings).
